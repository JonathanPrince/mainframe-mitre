# z/OS MITRE ATT&CK Dashboard (React + Tailwind)

## Quick start
```bash
npm install
npm run dev
```

## Build for static hosting
```bash
npm run build
npm run preview
```

The data file is served from: `public/data/zos-mitre-data.json`.
Replace it with a new export if needed (same shape).

Embedded dataset source: /mnt/data/zos-mitre-expanded-complete-with-detections.json
